# stefanahman/homebrew-tap

```sh
brew install --cask stefanahman/tap/pr-owl        # https://github.com/stefanahman/pr-owl
brew install --cask stefanahman/tap/tmux-spaces   # https://github.com/stefanahman/tmux-spaces
```

The casks are written by each project's release workflow (goreleaser);
nothing here is edited by hand.
