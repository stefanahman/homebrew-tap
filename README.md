# stefanahman/homebrew-tap

Homebrew packages for owl, spaces, mcp-defer and mindoro.

## Install

```sh
brew install --cask stefanahman/tap/owl
brew install --cask stefanahman/tap/spaces
brew install --cask stefanahman/tap/mcp-defer
brew install stefanahman/tap/mindoro
```

Each tool's release writes its package here. Edit the tool's release
config, not these files.
